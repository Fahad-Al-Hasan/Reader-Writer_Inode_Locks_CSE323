# Reader-Writer Inode Locks in xv6
This project aims to improve the inode locking mechanism of xv6 by implementing a reader-writer lock that allows multiple readers to access an inode simultaneously while ensuring writers do not experience starvation.

Project Objectives
- Support concurrent inode readers.
- Ensure exclusive access for writers.
- Prevent writer starvation.
- Evaluate synchronization performance.
